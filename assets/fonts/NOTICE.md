# Icon font notice

`HerdrAgentIconsMax-Regular.ttf` is the icon-only face shipped by
[hhdebb/herdr-radar](https://github.com/hhdebb/herdr-radar) (MIT runtime;
glyph design inherited from qintmb/herdr-icon-agent-ui). Vendor marks identify
third-party products and do not imply affiliation.

Muse has no glyph in that face; this plugin falls back to a text mark for it.

`HerdrAgentMiMo-Regular.ttf` is a one-glyph local face built from the official
Xiaomi MiMo square logo (same geometry as
`https://mimo.xiaomi.com/mimo-v2-pro/assets/logo.svg`, cropped to one cell) at
`U+E1B7`. Outlines only — the sidebar `fg` paints the mark, same as every
vendor glyph. It is **not** part of HerdrAgentIconsMax; keep that face
byte-identical to upstream.
